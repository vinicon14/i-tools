# Jeito Facil Ferramentas Livres

Build the first implementation of a polished, responsive Portuguese (Brazil) AI tools portal called ai-tools. Landing page and directory concept only; do NOT build working AI tools or imply they are live. Clearly communicate future tools will be free, supported only by ads, with no account, subscription, or paywall. Strong visual hierarchy, accessible contrast and keyboard focus, mobile-first layout, lightweight CSS/icon assets, no heavy stock images. Hero, value proposition, categories and planned tool cards explicitly marked as coming soon. Optional search should state tools are being prepared and return no fake live tools. Plan routing on one domain using /tools/<slug>, not subdomains. Include SEO title, description, Open Graph, semantic headings and descriptive links. Simple elegant contemporary visual identity. Do not publish or deploy.
